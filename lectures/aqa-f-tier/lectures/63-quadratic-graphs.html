Quadratic Graphs

Plotting and reading a curved graph whose equation contains x²

What This Is

A quadratic graph is a smooth U-shaped curve called a parabola. Its equation always contains an x² term — for example, y = x² − 2x − 3. To draw one, you substitute a set of x values into the equation, calculate the matching y values, plot the coordinate pairs, and join them with one smooth curve. Every AQA question at this level gives you the equation and an x value range, and asks you to complete a table and draw the graph.

Key Terms You Must Know

Quadratic equation

An equation where the highest power of x is 2. It always contains an x² term. Example: y = x² − 2x − 3.

Parabola

The U-shaped curve produced by every quadratic graph. It is perfectly symmetrical — the left half mirrors the right half exactly.

Table of values

A table where you substitute each x value into the equation to find its matching y value. Each row gives you one coordinate to plot.

Turning point (vertex)

The bottom of the U-shape (for a positive x² curve). It is the lowest point on the graph and sits on the line of symmetry.

Roots (x-intercepts)

The x values where the curve crosses the x-axis — i.e. where y = 0. A quadratic can have 0, 1 or 2 roots.

The Method — Step by Step
Grade 4–5 topic. You will be given the equation and the x values. Your job is to complete the table and draw the curve accurately.
1

Write the equation and identify every x value you must substitute

Read the equation and write it at the top of your working. This keeps you from misreading a sign when you are in the middle of a substitution.

List the x values from the question — the range the table gives you. For y = x² − 2x − 3 from x = −2 to x = 4, your list is: −2, −1, 0, 1, 2, 3, 4.

For y = x² − 2x − 3: equation written at top, x values listed: −2, −1, 0, 1, 2, 3, 4.
2

Substitute each x value and calculate the matching y value

Take the first x value and replace every x in the equation with that number. Work out x² first, then the middle term, then add or subtract the constant — in that order.

Be careful with negatives: (−2)² = 4, not −4. Squaring always gives a positive result. Write the bracket explicitly to avoid this error every single time.

Repeat for every x value in the table. Write the full calculation on the side — not the answer alone — so you can spot arithmetic mistakes before you plot.

For x = 1: y = (1)² − 2(1) − 3 = 1 − 2 − 3 = −4. For x = 3: y = 9 − 6 − 3 = 0.
3

Plot each coordinate pair on the axes

Take each (x, y) pair from your completed table and mark it with a small cross on the grid. Go to the x value first, then move up or down to the y value — exactly as with any coordinate pair.

Use a small, neat cross — not a dot or a blob. A cross is easier for an examiner to read and easier for you to join accurately. Place it exactly on the grid intersection — not between lines.

For y = x² − 2x − 3: plot (−2, 5), (−1, 0), (0, −3), (1, −4), (2, −3), (3, 0), (4, 5) — seven crosses on the grid.
4

Join all the points with one smooth, continuous curve

Pick up your pencil and draw one continuous curve through all the crosses. A parabola is never made of straight line segments — every part of it is curved, including between points that are close together.

Turn your paper if it helps you draw the curve more smoothly. Your wrist moves more naturally in some directions than others — rotating the page is not cheating, it is technique.

For y = x² − 2x − 3: draw one smooth U-curve through all seven crosses. The bottom of the U is at (1, −4).
5

In the event of a missing y value — the question asks you to complete the table

AQA often gives a partially completed table with one or two y values missing. Spot which x value has no y value in the table, then substitute that x value into the equation exactly as in Step 2.

Write the completed value into the table before you start plotting. Plotting from an incomplete table loses you a mark and produces a gap in your curve.

x = 1 is missing: y = (1)² − 2(1) − 3 = 1 − 2 − 3 = −4. Write −4 in the table, then plot (1, −4).
