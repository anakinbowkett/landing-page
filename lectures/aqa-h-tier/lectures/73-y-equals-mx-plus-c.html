y = mx + c

Reading gradient and y-intercept from a linear equation, then drawing the straight-line graph

What This Is

Every straight-line graph has an equation in the form y = mx + c. The letter m tells you the gradient — how steeply the line rises or falls. The letter c tells you the y-intercept — the exact point where the line crosses the y-axis. Once you know both values, you can draw the graph precisely: plot one point, use the gradient to find more, then rule a straight line through them all.

Key Terms You Must Know

Gradient (m)

The steepness of the line. It measures how much y increases for every 1 unit increase in x. A gradient of 2 means: go right 1, go up 2. A gradient of −3 means: go right 1, go down 3. The gradient is the number multiplying x in the equation y = mx + c.

y-intercept (c)

The y value where the line crosses the y-axis — where x = 0. In y = mx + c, the y-intercept is always the constant c at the end of the equation. Substituting x = 0 into any equation always gives the y-intercept, so c = y when x = 0.

Rise over Run

The definition of gradient as a fraction: rise ÷ run. "Rise" is the vertical change between two points. "Run" is the horizontal change. Gradient = rise ÷ run. You use this both to draw the line (from a known point, go run steps right and rise steps up) and to read the gradient from a graph.

x-intercept

The x value where the line crosses the x-axis — where y = 0. To find it algebraically, substitute y = 0 and solve for x. You can also read it directly from your drawn graph. The x-intercept is NOT the same as c — those are two different points on two different axes.

Table of Values

A two-row table listing x values in the top row and the corresponding y values in the bottom row. You build it by substituting each x into the equation. For a straight line, the y values increase (or decrease) by the same amount each time x increases by 1 — this gives you a quick check that your substitutions are correct.

Linear

A graph is linear when it produces a straight line. Every linear equation has x to the power of 1 only — no x², no x³. The equation y = mx + c is the standard form for any linear graph. If your graph is not a perfectly straight line, a substitution error has been made.

The Method — Step by Step
Grade 5–7 topic. On Edexcel papers, linear graph questions ask you to complete a table, plot points, and draw a ruled line — or to identify the equation of a line from a graph. Four marks: B2 for the table, P1 for correct points, A1 for a straight ruled line.
1

Read the gradient m and y-intercept c directly from the equation

Look at the equation in the form y = mx + c. The gradient m is the number written in front of x. In y = 2x + 3, the gradient is 2 because that is the coefficient of x.

The y-intercept c is the number at the end — the constant term with no x attached. In y = 2x + 3, the y-intercept is 3. Write down both values before drawing anything: m = 2 and c = 3.

For y = 2x + 3: write m = 2 and c = 3. These two values tell you everything about the line's position and angle. Plot the y-intercept next.
2

Plot the y-intercept at (0, c) on the y-axis

The y-intercept always has x = 0, so its coordinates are (0, c). For c = 3, the point is (0, 3). Find x = 0 on the x-axis — that is the y-axis itself — then count up 3 units and mark a cross.

This point (0, 3) lies exactly on the y-axis. Every line in the form y = mx + c crosses the y-axis at this height — c is the y-coordinate of that crossing. This is your anchor point. The rest of the line grows from here.

c = 3, so mark a cross at (0, 3). Now use the gradient to find more points along the line.
3

Use the gradient to step from one point to the next

From your y-intercept (0, 3), apply the gradient rule: move right 1 unit along the x-axis, then move up by m units. With m = 2, go right 1 and up 2. That lands on (1, 5). Repeat: from (1, 5), go right 1 and up 2 to reach (2, 7).

For a negative gradient, go right 1 and down by the absolute value of m. The gradient triangle is the same shape — the rise becomes negative. This is why a negative m produces a line that slopes downward from left to right.

From (0, 3): right 1, up 2 → (1, 5). From (1, 5): right 1, up 2 → (2, 7). Each step applies gradient m = 2 exactly. Complete the table values next.
4

Complete the table of values by substituting each x

For each x value in the table, replace x in the equation and calculate y. For y = 2x + 3, substitute x = −3: y = 2(−3) + 3 = −6 + 3 = −3. Write −3 in the y row under x = −3.

Repeat for every x value and complete the whole table. For a straight line, the y values increase by exactly m each time x increases by 1 — this means adjacent y values in the table differ by 2. Use this as a check: if any gap is not 2, recalculate that cell.

y at x=−3: 2(−3)+3=−3. y at x=0: 3. y at x=3: 9. Each y increases by 2 — confirming gradient 2 throughout. Plot these points next.
5

Plot every coordinate pair from the table as a precise cross

Set up labelled axes covering the full range of your table. For y = 2x + 3 with x from −3 to 3, the y values run from −3 to 9, so draw the y-axis from at least −4 to 10. For each (x, y) pair, locate x on the horizontal axis, find y on the vertical axis, and mark a small cross exactly at that grid intersection.

Check that your plotted points form a visually straight diagonal — if they do not, a substitution or plotting error exists. A linear graph's points always lie exactly on a straight line, so any point that looks out of place is wrong. Correct it before drawing the line.

Plot (−3,−3), (−2,−1), (−1,1), (0,3), (1,5), (2,7), (3,9) as crosses. They should form a perfect diagonal. Now rule the line.
6

Draw a single ruled straight line through all plotted points

Place a ruler so its edge passes through all plotted crosses and draw one continuous line from one end of the required x range to the other. The line must pass through every cross — if it misses even one, the A1 mark is at risk. Do not draw freehand for straight-line graphs.

Extend the line across the full range of x values the question specifies — from x = −3 all the way to x = 3. Do not stop the line at a plotted point. The mark scheme awards A1 for a straight ruled line that passes through all required points and extends across the stated domain.

Rule a straight line from (−3, −3) to (3, 9). The line passes through all 7 plotted crosses. Label it y = 2x + 3 if the question asks. That earns the A1.
7

In the event of: finding m and c from a given graph

Read the y-intercept c directly from the graph — find where the line crosses the y-axis and read off the y coordinate. Then choose two clear grid intersection points on the line and calculate the gradient: m = rise ÷ run = (change in y) ÷ (change in x).

Divide rise by run to get the gradient: 4 ÷ 2 = 2. Then write the equation: y = mx + c with your values substituted in. Here, m = 2 and c = 3, giving y = 2x + 3.

From the graph: c = 3 (y-intercept), rise = 4, run = 2 → m = 2. Equation: y = 2x + 3.
