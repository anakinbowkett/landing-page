Solving Quadratics by Factorising

Set to zero, find the factor pair, apply zero-product — Edexcel

What This Is

A quadratic equation has an x² term. To solve it means to find every value of x that makes the equation true. Factorising rewrites the quadratic as two brackets multiplied together. Once you have two brackets equal to zero, a single powerful rule does the rest: if two things multiply to give zero, then at least one of them must be zero. That rule turns a two-mark algebra problem into two one-step equations you can solve instantly.

Key Terms You Must Know

Quadratic Expression

An expression with x² as its highest power, written as ax² + bx + c. The coefficients a, b and c are numbers. In x² + 5x + 6, a = 1, b = 5 and c = 6. When this equals zero you have a quadratic equation to solve.

Factorising

Rewriting a quadratic as a product of two brackets: (x + p)(x + q). Expanding those brackets gives back the original expression, so the two forms are exactly equivalent. You are not changing the equation — you are rewriting it in a more useful form.

Factor Pair

Two numbers p and q such that p × q = c (the constant term) and p + q = b (the coefficient of x). Finding this pair is the core skill. For x² + 5x + 6: you need two numbers that multiply to 6 and add to 5. Those numbers are 2 and 3.

Zero-Product Property

If A × B = 0 then A = 0 or B = 0 (or both). This is the engine of the method. Once the quadratic is factorised as two brackets equal to zero, each bracket is set to zero in turn and solved as a simple linear equation.

Solution / Root

The values of x that satisfy the equation. A quadratic has two roots (they can be equal or they can be different). Write them as x = ___ or x = ___. Both roots must be stated — giving only one will lose the accuracy mark.

The Method — Step by Step
Grade 6–7 topic. Factorising quadratics appears on every Edexcel paper and feeds directly into harder algebraic topics at Grade 8–9.
1

Set the equation equal to zero before doing anything else

Check whether the equation already has zero on one side. If it does, move to Step 2. If it does not — for example x² + 5x = −6 — rearrange it now by adding or subtracting terms until everything is on one side and zero is on the other. The zero-product property only works when the right-hand side is exactly zero.

Read off the values of a, b and c from ax² + bx + c = 0. Write them down explicitly before searching for the factor pair. When a = 1 (the x² has no coefficient), the factorising method works directly. When a is greater than 1 the method is harder — this guide covers a = 1.

e.g. x² + 5x + 6 = 0 → a = 1, b = 5, c = 6  (already set to zero ✓)
2

Find two numbers that multiply to c and add to b

Write down all factor pairs of c — that is, all pairs of integers whose product is c. For c = 6, list them systematically: 1 × 6, 2 × 3, −1 × −6, −2 × −3. Writing the list prevents you from missing a pair, and the negative pairs matter when b is negative.

Check each pair against the target sum b. The correct pair is the one whose product equals c and whose sum equals b simultaneously. Circle or tick it when you find it. For x² + 5x + 6: the pair 2 and 3 multiplies to 6 and adds to 5 — this is the pair you need.

e.g. Need: × = 6, + = 5.   Pair: 2 and 3.   Check: 2 × 3 = 6 ✓ and 2 + 3 = 5 ✓
3

Write the two brackets using the factor pair you found

Write the factorised form as (x + p)(x + q) = 0, where p and q are the two numbers from your factor pair. Place x in both brackets — it appears exactly once in each. Place one factor number in each bracket after the x. Include the = 0 at the end; leaving it out turns an equation into an expression and costs marks.

Verify the factorisation by expanding the brackets mentally. Multiply the two x terms to get x². Multiply the outer and inner terms for the bx part: x × 3 + 2 × x = 5x. Multiply the constants: 2 × 3 = 6. This gives x² + 5x + 6, matching the original. If it does not match, the factor pair was wrong — go back and try again.

e.g. x² + 5x + 6 = 0 → (x + 2)(x + 3) = 0     check: x² + 5x + 6 ✓
4

Apply the zero-product property — set each bracket equal to zero

Write two separate equations, one from each bracket. The rule is: if two factors multiply to zero then each factor equals zero in turn. Write x + 2 = 0 below the left bracket and x + 3 = 0 below the right bracket. Do this as two clearly separate lines — do not write them on the same line.

Understand why this works. If (x + 2) × (x + 3) = 0, the only way that product can equal zero is if at least one of those brackets is itself zero. Any non-zero number multiplied by anything else cannot give zero. So both possibilities must be explored — one for each bracket.

e.g. (x + 2)(x + 3) = 0 → x + 2 = 0   or   x + 3 = 0
5

Solve each linear equation to find the two values of x

Solve x + 2 = 0 by subtracting 2 from both sides. Write the working explicitly: x + 2 = 0 → x = −2. The sign flips — the +2 in the bracket becomes −2 in the answer. Students who skip the working line sometimes sign-flip incorrectly. Write every step.

Solve x + 3 = 0 in the same way: subtract 3 from both sides to get x = −3. Now write both solutions together using the word "or" between them. A quadratic equation has two solutions — writing only one gives zero marks on the solution line even when the factorisation was correct.

Write the final answer as x = −2 or x = −3 on a single clear line. The word "or" is important — it signals two separate solutions, not a range. You can verify both roots by substituting each value back into the original equation and confirming that both give zero.

e.g. x + 2 = 0 → x = −2  |  x + 3 = 0 → x = −3  |  final: x = −2 or x = −3
6

In the event of a negative constant term — handle negative factor pairs carefully

Recognise a negative c-value as the signal that your two numbers must have opposite signs. For example, in x² + 2x − 8 = 0, c = −8. Two numbers with opposite signs always give a negative product. List factor pairs of −8: 1 × −8, −1 × 8, 2 × −4, −2 × 4. Only one pair will also sum to b = +2.

Write the factorised form with the opposite-sign pair and solve as before. For x² + 2x − 8 = 0, the pair is −2 and 4, giving (x − 2)(x + 4) = 0. Setting each bracket to zero gives x − 2 = 0 → x = 2 and x + 4 = 0 → x = −4. One solution is positive and one is negative, which matches the opposite signs in the pair.

e.g. x² + 2x − 8 = 0 → (x − 2)(x + 4) = 0 → x = 2 or x = −4
