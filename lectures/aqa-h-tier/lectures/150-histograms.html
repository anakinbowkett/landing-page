Histograms

Reading and drawing histograms with unequal class widths — AQA Higher

What This Is

A histogram looks like a bar chart, but it works differently — the area of each bar represents the frequency, not the height. You use this when data is grouped into classes that are not all the same width. The key number you calculate is called frequency density, and once you know it, everything else follows from it.

Key Terms You Must Know

Frequency Density

The height of a bar in a histogram. Calculated as Frequency ÷ Class Width. It is the frequency per unit of the class interval — never the raw frequency itself.

Class Width

The size of a grouped class interval. For the class 10 ≤ t < 20, the class width is 20 − 10 = 10. Always subtract the lower boundary from the upper boundary.

Frequency

The number of data values that fall inside a class interval. In a histogram, frequency = frequency density × class width. This is the area of the bar, not its height.

Unequal Class Widths

When grouped data uses intervals of different sizes — for example 0–5, 5–10, 10–20, 20–40. Histograms are used precisely because a bar chart would give a misleading picture when class widths differ.

Continuous Data

Data that can take any value in a range — measurements like time, height, or weight. Histograms are drawn for continuous data only. The bars touch each other because there are no gaps between possible values.

The Method — Step by Step
Grade 6–8 topic. Histograms with unequal class widths are an AQA Higher staple. The formula is simple — the challenge is applying it correctly in both directions: given frequency to find height, and given height to find frequency.
1

Write down the formula: Frequency Density = Frequency ÷ Class Width

Write the formula at the top of your working: Frequency Density = Frequency ÷ Class Width. This is the single rule that controls everything in a histogram question — every other step flows from it.

Rearrange this formula now, before the question begins. You need two versions ready: Frequency = FD × Class Width and Class Width = Frequency ÷ FD. Exam questions switch between all three forms.

2

Calculate the class width for each row

Look at each class interval in the table. Subtract the lower boundary from the upper boundary to find the class width. For 10 ≤ t < 20, the class width is 20 − 10 = 10. Do this for every row before you do anything else.

Check that your class widths cover the full data range without overlap or gap. Adjacent class upper boundaries and lower boundaries must meet exactly — the end of one class is the start of the next. This confirms your subtraction is correct.

3

Divide each frequency by its class width to get frequency density

Take the frequency for a class and divide it by that class's width. Write the result in a new column labelled "Frequency Density". This number becomes the height of the bar you draw for that class. Do this for every row.

Notice how the class with the biggest frequency (30) does not produce the tallest bar — because its class width (10) is larger than the first two classes. Frequency density levels the playing field across unequal classes. That is the entire reason you calculate it.

4

Draw each bar: width matches the class interval, height equals the frequency density

Draw the horizontal axis and mark on all the class boundaries as numbers — not the midpoints, not labels, just the boundary values (0, 5, 10, 20, 40 and so on). Make sure the spacing between boundary marks is proportional to the actual class widths — a class of width 10 must take twice the space of a class of width 5.

Draw the vertical axis labelled "Frequency Density". Scale it so your largest frequency density value fits comfortably near the top. Draw each bar from its lower class boundary to its upper class boundary, with the top of the bar sitting at the frequency density value for that class. The bars must touch — no gaps between them.

5

Read frequency back from a histogram: Frequency = FD × Class Width

When a histogram is given and you need to find the frequency, read off the height of the bar from the vertical axis — this is the frequency density. Then read the class width from the horizontal axis by subtracting the left boundary from the right boundary of that bar.

Multiply the frequency density by the class width: Frequency = FD × Class Width. For the bar above (class 10 ≤ t < 20, FD = 3, width = 10): Frequency = 3 × 10 = 30. Write this calculation in full — the mark scheme awards the method mark for showing this multiplication.

6

In the event of a partially completed histogram — find the missing frequency or fill the missing bar

Exam questions often give you a histogram with one bar missing and a table with one frequency missing. Use the bars that are already drawn to work out the frequency densities for those classes — verify they match the table. Then use the known frequency in the table to calculate the frequency density for the missing bar, and draw it.

If the table gives you the frequency for the missing bar but the histogram needs you to draw it: calculate FD = Frequency ÷ Class Width, then draw the bar at exactly that height. If the histogram shows you the missing bar but the table needs the frequency: read the FD from the bar height, then multiply by the class width. Both directions use the same formula — just decide which quantity is missing before you start.
