Error Intervals and Bounds

Finding the smallest and largest values a rounded number could have been

What This Is

When a number has been rounded, you don't know the exact value — only a range it must lie in. That range is called the error interval. The smallest value in the range is the lower bound and the largest value that rounds down to your number is the upper bound. You write the error interval as an inequality using ≤ and < to show which end is included and which is not.

Key Terms You Must Know

Error Interval

The range of values a number could have before it was rounded. Written as a double inequality: lower bound ≤ x < upper bound.

Lower Bound

The smallest value that rounds up to the given number. It uses ≤ because this exact value is included in the range.

Upper Bound

The smallest value that would round up to the next number. It uses < because this exact value is NOT included — it would give a different answer.

Degree of Accuracy

The precision a number has been rounded to — for example, 1 decimal place, the nearest 10, or 2 significant figures.

Half the Precision

The key calculation: you always add and subtract half of the unit of rounding. For 1 d.p., the unit is 0.1, so half is 0.05.

The Method — Step by Step
1
Read the degree of accuracy from the question

Read the question carefully and identify exactly what precision the number has been rounded to. The question will say something like "rounded to 1 decimal place", "rounded to the nearest 10", or "rounded to 2 significant figures". This tells you the size of one unit of rounding — the number you will halve in the next step.

Write down the unit of rounding as a plain number. For 1 decimal place, the unit is 0.1. For the nearest whole number, the unit is 1. For the nearest 10, the unit is 10. For 2 significant figures on a number like 340, the unit is 10. You need this written down before the next step.

Example: "34.7 cm, rounded to 1 decimal place" → the unit of rounding is 0.1
2
Halve the unit of rounding

Divide the unit of rounding by 2. This gives you the value you will add and subtract from the rounded number. The logic is this: any value within half a unit below or above the rounded number would round to that number, so half the unit marks the boundary on each side.

Write this value down clearly — you will use it twice, once to find the lower bound and once to find the upper bound. For 34.7 rounded to 1 d.p., you write 0.05 as your working value before the next calculation.

0.1 ÷ 2 = 0.05 — this is the value you will add and subtract from 34.7
3
Subtract to find the lower bound

Take the rounded number and subtract the half-precision value. The result is the lower bound — the smallest value that rounds up to the given number. Anything below this lower bound would round to a smaller number instead, so it marks the left-hand edge of the error interval.

The lower bound uses the ≤ sign because the exact value 34.65 is included — it rounds to 34.7 and not to 34.6. Write this as the left side of your error interval: 34.65 ≤ x.

34.7 − 0.05 = 34.65 → lower bound is 34.65
4
Add to find the upper bound

Take the rounded number and add the half-precision value. The result is the upper bound. This value is the first number that would round up to the next value (34.8) rather than back to 34.7, so it falls immediately outside the range. That is why it uses the strict less-than sign < rather than ≤.

The upper bound uses the strict less-than sign < because 34.75 itself would round to 34.8, not 34.7. The range ends immediately before it. Write the complete error interval: 34.65 ≤ x < 34.75. The open circle on the number line and the open bracket on paper both show this.

34.7 + 0.05 = 34.75 → upper bound is 34.75 → error interval: 34.65 ≤ x < 34.75
5
In the event of — bounds used in a calculation

Some questions give two rounded measurements and ask for the upper or lower bound of a calculated value — such as the upper bound of an area, or the lower bound of a speed. Find the bounds of each measurement first, then decide which combination of bounds gives the largest or smallest result for the calculation.

For division, the rule reverses: to find the upper bound of a fraction, use upper ÷ lower. To find the lower bound, use lower ÷ upper. Always state which bound you are finding and show both the bounds you used in your calculation — the mark scheme awards a method mark for this.

A length of 34.7 cm and a width of 12.3 cm both to 1 d.p. → upper bound of area = 34.75 × 12.35

34.7 − 0.05 = 34.65

STEP 4 — Add for upper bound

STEP 5 — Final answer

Combine the two bounds into a double inequality. The left side uses ≤ because the lower bound is included. The right side uses strict < because the upper bound is excluded. The variable l sits in the middle.
